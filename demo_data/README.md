# SahiNaksha Synthetic Demo Dataset

**SYNTHETIC / DEMO DATA — NOT REAL SURVEY DATA**

- sample_orthomosaic.ppm — tiny P3 RGB raster fixture representing a synthetic scene.
- reference_parcels.geojson — four synthetic reference parcels in LOCAL_IMAGE_0_100 space.
- expected_final_output.geojson — expected reviewed output structure.
- provenance.json — source, synthetic flag, coordinate-space and legal-status metadata.

The PPM raster is deliberately tiny and human-readable. The current production upload route accepts JPG/JPEG/PNG; convert this fixture to PNG for an upload test.
